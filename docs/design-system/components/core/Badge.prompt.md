**Badge** — small tonal status/category label.

```jsx
<Badge tone="emerald">Agendado</Badge>
<Badge tone="positive" icon="check-check">Confirmado</Badge>
<Badge tone="warning">Pendente</Badge>
<Badge tone="gold">♠ Poker</Badge>
```

Tones: neutral · gold · emerald · positive · negative · warning · solid (gold fill). Pair payment states as warning→Pendente, neutral→Pago, positive→Confirmado.
