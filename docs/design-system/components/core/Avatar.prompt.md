**Avatar** — player initials on a felt chip, optional podium ring + corner badge.

```jsx
<Avatar name="Bruno Lima" />
<Avatar name="Ana Reis" podium="gold" badge="1" badgeGold />
<Avatar name="Org" badgeIcon="crown" badgeGold size={52} />
```

- `podium` adds a gold/silver/bronze ring.
- `badge` (number) or `badgeIcon` (Lucide, e.g. crown for organizer) renders a corner chip.
