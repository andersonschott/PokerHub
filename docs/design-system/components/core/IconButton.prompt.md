**IconButton** — icon-only square control, ≥44px touch target. For headers, toolbars, and table-row actions.

```jsx
<IconButton icon="copy" variant="solid" />
<IconButton icon="settings" />
<IconButton icon="crown" gold variant="solid" />
```

- `variant`: ghost (default) · solid (chip surface + border)
- `size`: md (44) · sm (36)
- `gold` tints the glyph with the organizer/primary accent.
